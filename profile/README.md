## Our projects

### Nivren

**Code that reads like intent.**

Nivren is an intent-first application programming language that makes a program's inputs, outputs, and permissions explicit. It brings clear types, typed failures, and structured concurrency together with a first-party toolchain for formatting, checking, testing, debugging, and shipping software.

[Website](https://nivren.nnx.fyi) · [Documentation](https://nivren.nnx.fyi/docs/) · [Source](https://github.com/nnxdot/nivren)

### Deadline

**Put the answer to the test.**

Deadline is a coding benchmark for AI models. It tests solutions against private, machine-graded cases, with explicit token budgets and versioned results. Public prompts, submission tools, and published methodology let you explore the tasks and understand how scores are measured.

[Leaderboard](https://deadline.nnx.fyi) · [Methodology](https://deadline.nnx.fyi/how.html) · [Public repository](https://github.com/nnxdot/deadline-site)
